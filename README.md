# Pingul public pages

Static public documents (privacy policies and similar) for Pingul apps and games.

Live site: <https://fkupper.github.io/public-pages/>

This repository is public on purpose. Do not put secrets, keys, or unreleased game source here.

## URLs

| Page | Path |
| --- | --- |
| Home | [/](https://fkupper.github.io/public-pages/) |
| Flip Treasure privacy | [/flip-treasure/privacy/](https://fkupper.github.io/public-pages/flip-treasure/privacy/) |

Paste the Flip Treasure privacy URL into Google Play (App content → Privacy policy, and the store listing).

## Add a page for another project

1. Create `your-project/page-name/index.html` (a folder with `index.html` so the URL has no `.html`).
2. Reuse `../../css/site.css` from a two-level folder, or adjust the relative path.
3. Add a card on the home page (`index.html`).
4. Push to `main`. GitHub Pages publishes from the root of `main`.

## Contact on policies

Privacy pages should name a way to reach you. The Flip Treasure page currently points at [github.com/fkupper](https://github.com/fkupper) and the Play listing support email. Add a dedicated public email on that page if you have one.
